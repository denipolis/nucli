## Project license

MIT (`LICENSE`). Anyone may use, change and redistribute the code as long as the copyright and license notice stay with it. Every bundled dependency and asset below is compatible with it.

Builds are not code signed for distribution (macOS builds are ad-hoc signed, not notarized; Windows builds are unsigned).

## Network and data

Nucli makes no network calls and collects no telemetry. It runs local processes (the user's shells and agents, `git`) and stores settings, state, restored terminal output and a conversation title cache in the folders listed in `docs/SPEC.md`.

It reads, never writes, files that agents store locally, only to show them in Nucli: conversation files (`~/.claude*/projects`, `~/.codex*/sessions`, `~/.pi/agent/sessions`) for titles, ids and folders, and Claude Code's per-process status files (`<config dir>/sessions/<pid>.json`: session id and status) for tab status and resume. It never reads the `<pid>.<hash>.key` files next to them, which hold secrets. On macOS, the first launch reads Nucli 1's preferences (`uk.polishch.nucli`) once to import them. Nothing leaves the machine. The formats of these files belong to their vendors and may change. Any change to this section needs a privacy review.
